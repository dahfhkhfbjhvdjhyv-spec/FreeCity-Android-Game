# AppMarket Guardian — Android app 2

Independent monitoring companion.

Planned functions:
- Check authenticated backend health.
- Show last successful Telegram webhook event and uptime history.
- Notify the owner when the backend becomes unavailable.
- Provide recovery instructions and alert history.

Android background execution is best-effort and subject to battery restrictions. The cloud backend, not this app, is the always-on service. Automated cloud restart requires a separately authorized hosting-provider integration.
