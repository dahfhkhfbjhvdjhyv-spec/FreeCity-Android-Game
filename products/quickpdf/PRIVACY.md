# QuickPDF Privacy Notice

QuickPDF 1.0 processes text and images selected by the user locally on the Android device to create PDF files. The app does not request internet access, does not create an account, and does not include ads, analytics, or third-party tracking in this version.

Generated files are saved in the app's Documents folder. When the user chooses Share, Android shares the selected PDF with the app or person chosen by the user.

The user controls which images are selected through Android's document picker. QuickPDF does not browse the user's photo library.

This notice describes the initial source implementation and must be reviewed again before release if app features or dependencies change.
